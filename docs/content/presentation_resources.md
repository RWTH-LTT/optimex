# Economic optimization in Optimex

Resources accompanying Luca Lange's bachelor's thesis presentation on cost optimization of transition pathways based on time-explicit life cycle assessment.

## Documentation

[Economic optimization guide](https://github.com/langeluca/optimex/blob/main/docs/content/economic_optimization.md)

Cost boundaries, time-specific prices, discounting, objectives and environmental constraints in the reusable Optimex extension.

## Getting started

[Basic economic example](https://github.com/langeluca/optimex/blob/main/notebooks/basic_example_econ.ipynb)

A compact workflow with synthetic data, including impact minimization, cost minimization and an environmental constraint. No ecoinvent data are required for this example.

## Reproduce the case study

[Ethylene case-study notebook](https://github.com/langeluca/optimex/blob/main/notebooks/ethylene_case_study.ipynb)

Product-system construction, assumptions, scenarios, optimization and result exports for the illustrative ethylene case study. The presentation uses advanced technology maturation combined with the electrification-favorable price scenario.

The repository provides the implementation and notebooks. Follow the installation and data requirements stated in each notebook.
